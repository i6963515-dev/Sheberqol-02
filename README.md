# SheberQol — веб-нұсқа

Бұл жоба бастапқы SheberQol React Native/Expo қосымшасының негізгі көріністерін қарапайым HTML, CSS және JavaScript арқылы қайта жасайды.

## Файлдар
- `index.html` — сайт құрылымы
- `style.css` — дизайн және мобильді бейімдеу
- `script.js` — каталог іздеуі, бөлім ауыстыру, контраст режимі, браузер арқылы дыбыстау және демонстрациялық жариялау ағымы
- `assets/` — бастапқы жобаның белгішелері

## GitHub Pages арқылы жариялау
1. Репозиторийге осы буманың ішіндегі файлдарды жүктеңіз (`index.html` түбірде тұруы керек).
2. GitHub репозиторийінде **Settings → Pages** ашыңыз.
3. **Deploy from a branch** таңдаңыз, branch ретінде `main`, folder ретінде `/ (root)` таңдаңыз да сақтаңыз.

Сайт статикалық болғандықтан Node.js орнатудың қажеті жоқ.

## Ескерту
ЖИ сурет талдауы демонстрациялық түрде көрсетілген. Kaspi төлемі, сервер, аккаунт және нақты ЖИ API интеграциялары бұл нұсқаға кірмейді. Браузердегі қазақша дыбыстау құрылғыда қолжетімді дауыстарға байланысты.


### Каталог фотолары
Каталогтағы өнім фотолары Unsplash сурет серверінен жүктеледі, сондықтан оларды көрсету үшін интернет қажет. «Бұйымды фотоға түсіру» батырмасы телефон камерасынан фото таңдауға мүмкіндік береді.


## Логотип пен фотолар
- `assets/logo.svg` — SheberQol латынша логотипі.
- `assets/images/` — каталогта қолданылатын жергілікті фотосуреттер. Фотоларды сайт интернетке қосылмай тұрса да көрсетуге болады.
